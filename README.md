## Proyecto principal

### [Club Ledger](https://github.com/yoerguille/club_ledger)

Aplicación web para gestionar cuentas de clubes deportivos por temporada: registrar cargos y pagos, consultar saldos y generar estados de cuenta.

**Python · Django · PostgreSQL · Tailwind CSS**

Proyecto personal en desarrollo, con código público.
